# azasimu2

Seal Colony Manager MVP is a small canvas-based simulation focused on visual readability. The MVP shows a seal fishing, carrying fish to a larger food storage building, and eating when hungry.

## Run locally

Open `index.html` directly in a browser, or serve the folder with a static file server:

```bash
python3 -m http.server 4173
```

Then visit <http://127.0.0.1:4173/>.

## Development checks

```bash
node --check src/game.js
```
